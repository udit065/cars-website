# 🚗 Retro Rides

A multi-page showcase website for classic and vintage cars.

**Live demo:** https://retro-rides.netlify.app/

## Pages
- **Home** with a car gallery
- **Car profiles**: 12 pages, one for each car
- **Our Services**
- **About Us**
- Shared navbar and footer

## Tech stack
HTML5 · CSS3 · JavaScript, deployed on Netlify

## Run locally
Open `index.html` in a browser, or serve the folder:
```bash
npx serve .
```
